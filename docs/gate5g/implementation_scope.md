# GATE-5G Implementation Scope

## Required implementation

1. Versioned governance policy and study registry.
2. Request and response contracts.
3. Deterministic validation and policy engine.
4. Reason codes and authority enforcement.
5. SHA-256 audit hash chain.
6. Read-only Study 1 adapter.
7. Independent partial Study 2 adapter.
8. Cross-study isolation tests.
9. Governed versus ungoverned Study 1 evaluation.
10. Reproducible command-line demonstration.

## Current foundation phase

This phase creates governance specifications and configuration only. It does not add executable code, alter evidence, or introduce Study 2 data.

## Excluded from the current prototype

- Autonomous network remediation
- Production deployment
- Live network actuation
- Cross-study dataset merging
- Completion of all Study 2 experiments
- Reuse of Study 1 thresholds for Study 2
- External databases
- Blockchain storage
- Unnecessary interface or infrastructure work

Implementation must remain limited to code necessary for the approved governance scope.
